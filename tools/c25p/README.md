# C25P Strong Feature Tools

These scripts are lightweight scaffolds for C25P raw/frame/strong-feature preflight work. They default to dry-run behavior and are intended to write any pilot cache under `/tmp/c25p_feature_cache/CONQUER-RLEM-c2c3`.

Do not use these tools to download TVQA/TVR data, bypass license terms, run official validation, read official prediction pools, or extract full feature matrices without explicit authorization.

# C26S Helpers

C26S restores the C17/C26R multi-span proposal row-space and tests PREM-style
span ranking plus span-to-video feedback. Official validation, official
prediction pools, pseudo-official selection, evaluator edits, and NMS edits are
forbidden.

Large joined score tables live under `/tmp/c26s_score_cache/CONQUER-RLEM-c2c3`
and are not committed.
